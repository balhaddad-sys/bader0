# NeuroLocalize 1.8.0

Offline neurological-localization study app (Android WebView shell + HTML/JS content).
This folder holds the unpacked 1.1.0 APK, the 1.2 and 1.3 enhancements and a reproducible build.

## What's new in 1.8.0
- **Fuller case explanations (all 120 cases)** in `web/explain.js`: what each finding tells you, the
  anatomy behind the best answer, and a specific reason for every option, shown in tutor feedback,
  session results and exam review.
- **The right figure for each case**: every case now names its most relevant figures (best first)
  instead of the first figure for its region; extra relevant figures appear as thumbnails.
- **Figure reading guides (all 35)** in `web/figguide.js`: orientation, what each labelled element
  means, how to use it at the bedside, and its limits, in the lesson, case and zoom views.
- **Deeper lessons**: a "Why it works" paragraph under each of the 51 lesson sections, and lesson
  figures ordered by relevance.

## What's new in 1.7.0
- **Exam mode**: build a mock paper (10, 20 or 40 questions; untimed, 90 s or 60 s per question;
  difficulty; any mix of regions). Answer freely, flag questions, jump with a question palette, and
  submit with a warning for unanswered and flagged items. The timer runs on the clock, survives
  closing the app and auto-submits at zero. Results show score, time, breakdowns by region and
  question type, a review of every question (missed and flagged first) and one-tap practice of the
  missed cases. Past exams are kept as history with your best score.
- **Study mode**: a guided 25-minute focus session for one region: read the lesson, study a figure,
  reason through five cases, review the region's recall cards and run its drill. Steps tick off
  automatically as you complete them, then it suggests an exam on that region.

## Layout
- `web/` – app assets (packaged as `assets/` in the APK)
- `base/` – original native shell: manifest, dex, resources (the build sets the app ID and version)
- `tools/diagrams.py` – diagram generator · `tools/build_apk.py` + `tools/signer/` – packaging/signing
- `dist/NeuroLocalize-1.8.0.apk` – built, v2-signed APK

## Build
```
python3 tools/diagrams.py web/assets/atlas
python3 tools/build_apk.py --apksig apksig-2.3.0.jar   # from Maven Central: com.android.tools.build:apksig
```
A signing key is created in `signing/` (git-ignored) on first build. Keep it: future updates must
be signed with the same key.

The application ID is `com.neurolocalize.study` (1.2.0–1.8.0 builds before this used `com.neurolocalize.app`; 1.1.0 used `org.neurolocalize.academy`). The build
renames the manifest package and writes the activity's full class name, the same way
`aapt2 --rename-manifest-package` does, so the compiled code keeps its original Java package.
Because the ID changed, 1.2.0 installs as a separate app next to 1.1.0, and study progress from
1.1.0 does not carry over.
